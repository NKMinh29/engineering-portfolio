# Khi nào một repo đủ để giới thiệu?

- README có bài toán, trạng thái, cách chạy, output và giới hạn.
- Có một luồng demo hoàn chỉnh; command được thử trên môi trường ghi rõ.
- Có test cho các lỗi quan trọng của bài toán, không chạy test chỉ để tăng số lượng.
- Số đo truy được về cấu hình/dataset/raw output; mục tiêu chưa đạt được ghi là mục tiêu.
- Mã tự viết, code nhóm và dependency được ghi nhận đúng.
- File cấu hình máy cá nhân, credentials, raw data lớn không được đưa vào commit nhầm.
- Issues mô tả công việc tiếp theo; release notes nói đúng phần đã hoàn thành.
- Người khác tải xuống biết bắt đầu ở đâu trong vài phút.

Chọn license khi đã rõ quyền của từng nhóm file. Đối với firmware có SDK, tránh áp một license mới cho toàn bộ tree chưa phân loại.
